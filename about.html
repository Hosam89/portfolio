About

From the factory floor to the cloud.

Full stack developer building web applications end to end, from database to interface.

Profile

I'm a full stack developer at Bornemann AG in Goslar, working across the whole stack: NestJS services and data layers on AWS, React frontends, and the infrastructure that runs them. Recent projects include a high-throughput backend on Kafka, a React/WebSocket platform for configuring devices, and a GraphQL-based logbook system.

Before that, I taught full-stack development at the Digital Career Institute, mentoring a cohort of students through React, Node.js and REST API development.

My path into software started in engineering. I studied mechatronics and mechanical engineering, and worked as a plant and machine operator at Hengst Filtration, keeping production running. That engineering background still shapes how I build software: systematically, and with the whole system in view.

What I focus on

Clean architecture, maintainable code and applications that stay fast under load. My core stack is TypeScript, React, Node.js, NestJS, AWS and REST/GraphQL.
